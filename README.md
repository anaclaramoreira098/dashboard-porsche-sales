🏎️ Dashboard de Vendas — Porsche Elegante

Este projeto é uma página web interativa que simula um Dashboard de Vendas da Porsche. Ele foi desenvolvido como desafio prático do Bootcamp da DIO, unindo estruturação de dados no Excel, geração de código por Inteligência Artificial e hospedagem no GitHub Pages.   

🔗 Acesse o Dashboard online: https://anaclaramoreira098.github.io/dashboard-porsche-sales/

❓ Perguntas de Negócio Escolhidas e KPIs

Para orientar a construção do dashboard e a extração de métricas, defini as seguintes perguntas de negócio e KPIs essenciais:   
1. Quais os principais modelos de carro vendidos por cidade? (KPI focado em identificar preferências regionais para direcionar o estoque).
2. Qual o ano de modelo de carro que mais saiu em um determinado período? (KPI para analisar tendências de mercado, renovação de frota e volume de saída temporal).
3. Quais são os insights de carros mais populares com base nos dados de cada cidade? (Para focar campanhas de marketing locais nos veículos com maior aceitação de vendas em cada região).

🛠️ Tratamento da Base de Dados

Antes de enviar os dados para a IA gerar os gráficos da página web, a base bruta precisou ser tratada.
Utilizei o Microsoft Excel para limpar os dados e criei Tabelas Dinâmicas para resumir as informações (consolidando o volume de vendas por modelo, por ano e por cidade). Esse tratamento foi crucial para entregar à IA apenas os números finais e consolidados.

🤖 Uso de IA: Canvas vs. Agentes

O curso abordou a utilização de Agentes (GPTs personalizados) para a criação dos dashboards. No entanto, como a criação de Agentes é um recurso restrito ao plano pago (ChatGPT Plus), adaptei o meu fluxo de trabalho para utilizar as ferramentas gratuitas disponíveis:   
- O que eu usei: Utilizei exclusivamente o ChatGPT com Canvas.   
- Como fiz: Gerei o código base pelo Canvas, copiei os arquivos para o meu ambiente local usando o VS Code (Visual Studio Code), fiz os ajustes manuais necessários e realizei o versionamento para o GitHub via terminal/VS Code.
